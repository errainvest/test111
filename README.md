# ERRA — база знаний и агент по налогообложению недвижимости

Внутренний инструмент для расчёта налоговой нагрузки по земельным сделкам ERRA
(Гедера Запад, Кфар-Йона Запад, Тверия — сельхозземля под смену назначения).

⚠️ **Не является налоговой консультацией.** Каждая ставка, сумма и дата требуют проверки
по действующей инструкции Налогового управления и/или у бухгалтера-ревизора либо
налогового адвоката перед использованием в финансовом решении.

## Структура

```
.claude/agents/mas-mekarkein.md   — агент Claude Code (системный промпт)
knowledge/                        — база знаний на иврите (агент читает её перед ответом)
  01-mas-rechisha.md              — налог на приобретение, группа покупателей, объединение недвижимости
  02-mas-shevach.md               — налог на прирост, линейный расчёт, временная льгота, разбивка
  03-heitel-hashbacha.md          — сбор за улучшение, оценки, возражения, замена сбора
  04-maam.md                      — НДС, случайная сделка, правило 6б
  05-yachid-mul-chevra.md         — ⚠️ физлицо против компании; когда физлицо облагается как бизнес
  06-yiud-karka.md                — ⚠️ сравнение по назначению земли
  07-erra-projects.md             — данные по проектам (требует заполнения)
docs/RU-spravochnik.md            — русскоязычный справочник для изучения
```

## Использование

Агент вызывается в сессии Claude Code как `mas-mekarkein`. Перед ответом он обязан
прочитать релевантный файл из `knowledge/` и не отвечать по памяти.

## Три встроенных красных флага

Агент поднимает их по собственной инициативе, не дожидаясь вопроса:

1. **Переквалификация в предпринимательскую деятельность** — до 50% вместо 25%, плюс
   Битуах Леуми и НДС. Модель ERRA (покупка сельхозземли под смену назначения) по
   определению является деятельностью по улучшению, поэтому риск встроенный.
2. **Группа покупателей (ст. 9(а))** — база налога может стать стоимостью готового
   объекта, а не земли. Эффект **не односторонний**: вредит владельцу второй квартиры,
   может быть выгоден покупателю единственной.
3. **Аренда у RMI против частной собственности** — при смене назначения арендованная
   земля возвращается RMI за ограниченную компенсацию (решение 1470). Проверка выписки
   из табу — шаг №1 в любом проекте.

## Обновление

Ставки и ступени меняются ежегодно в январе. При обновлении править файлы в `knowledge/`
и проставлять дату в заголовке файла. Незаполненные поля в `07-erra-projects.md`
помечены ❓ — их отсутствие блокирует точную модель доходности.
